## 📌 Sobre o projeto

O **MindDoc Analyzer** é uma aplicação para extração e organização de informações de documentos, desenvolvida por meio da **API — Aprendizagem por Projetos Integrados**, durante o 2º semestre do curso de Análise e Desenvolvimento de Sistemas da **FATEC São José dos Campos — Prof. Jessen Vidal**.

Seu objetivo é facilitar o acesso e a análise de informações extraídas de **relatórios clínicos no contexto da saúde mental**. A aplicação utiliza modelos de inteligência artificial para extrair dados como diagnósticos, tratamentos e evolução do paciente, organizando essas informações para consulta e revisão pelos profissionais.

> 💡 Inteligência artificial com processamento local: o projeto foi desenvolvido para executar na máquina do usuário, considerando a privacidade dos dados e a independência de APIs externas.

## 👩‍💻 Minha atuação

### Desenvolvedora Full Stack · Dev Team

Atuei como **desenvolvedora full-stack na equipe AdaLove**, contribuindo para o desenvolvimento da lógica da aplicação com **Java**, a persistência de dados com **MySQL** e os ajustes de interface e estilização com **CSS**.

## 📅 Entregas por Sprint

| **Etapas** | **Principais entregas** |
| :--- | :--- |
| **Sprint I** | Extração automática de informações, interfaces de cadastro e exibição dos dados e estrutura inicial de controle de acesso. |
| **Sprint II** | Persistência em banco de dados, edição e exclusão de registros e execução local da aplicação. |
| **Sprint III** | Consulta e filtragem de relatórios, seleção de modelos, autenticação e melhorias na interface. |
| **Sprint IV** | Testes, correção de falhas, otimização e documentação de uso. |
